Install Gill Sports on your iPhone

In Safari, open this website, tap Share, then Add to Home Screen. The app icon opens Gill Sports directly. This does not grant access to private workflows or store a GitHub token. Use Run in GitHub (no token) while signed in to GitHub for manual jobs.

A network connection is required for current predictions, sportsbook prices and workflow actions. Saved shell pages do not make stale data live.
